# 🌶️ Jyoti Masala Box (ज्योति मसाला बॉक्स)

> **घर का स्वाद, असली मसाले और दादी-नानी के सिद्ध घरेलू नुस्खे**

एक संपूर्ण और प्रीमियम भारतीय कुकिंग वेब ऐप्लिकेशन जिसमें किचन के आपातकालीन नुस्खे (Emergency Kitchen Hacks), असली सीक्रेट मसालों की विधियां, पारंपरिक रेसिपीज़, व्हाट्सएप/कॉलिंग सपोर्ट, ज्योति दीदी चैटबॉट, श्री गणेश जी का 3D फूलों की बारिश वाला मंदिर, सुरक्षित एडमिन पैनल और कस्टमाइज़ेबल UPI पेमेंट क्यूआर कोड शामिल हैं।

---

## ✨ मुख्य विशेषताएं (Key Features)

### 1. 💡 घरेलू टिप्स एवं ट्रिक्स (Kitchen Hacks & SOS Tips)
- **सब्जी में ज्यादा तेल हो जाए तो क्या करें**: उबला आलू, भुना बेसन या बर्फ का टुकड़ा घुमाने की असरदार ट्रिक।
- **दाल जलने पर क्या करें**: ऊपर की दाल अलग करके देसी घी का जीरा-हींग तड़का और कच्चा प्याज/टमाटर की स्लाइस ट्रिक।
- **हलवाई जैसी कुरकुरी जलेबी**: चाशनी का सही 1-तार अनुपात और गर्म तेल में तलने का राज।
- **सॉफ्ट और जालीदार खमन ढोकला**: सही मात्रा में साइट्रिक एसिड और ईनो डालकर एक ही दिशा में फेंटने का सीक्रेट।
- **सब्जी में ज्यादा नमक या तीखापन ठीक करने के त्वरित उपाय**।

### 2. 🌿 सीक्रेट मसाला फॉर्मूला (Secret Homemade Spice Formulas)
- **दाल मसाला (Daal Masala)**
- **शाही चिकन मसाला (Shahi Chicken Masala)**
- **रॉयल मटन मसाला (Royal Mutton Masala)**
- **शाही गरम मसाला, पाव भाजी मसाला, सांभर मसाला, छोले मसाला, चाट मसाला** आदि।
- *हर मसाले के साथ सामग्री का सटीक ग्राम में अनुपात, भूनने का सही तापमान और सुरक्षित स्टोर करने की तकनीक।*

### 3. 🍲 संपूर्ण रेसिपी डायरेक्टरी (Authentic Recipe Directory)
- दाल तड़का, कड़ाही पनीर, शाही मटन करी, गुजराती खमन ढोकला, कुरकुरी जलेबी, दम बिरयानी आदि।
- सामग्री, समय, सर्विंग्स और स्टेप-बाय-स्टेप हिंदी निर्देश।

### 4. 🛕 श्री गणेश जी मिनी-मंदिर (Shree Ganesha Shrine)
- हेडर में सुंदर और पावन श्री गणेश जी की मूर्ति।
- मूर्ति के फ्रेम के भीतर निरंतर 3D गुलाब की पंखुड़ियों (Petals) की बारिश का मनमोहक एनीमेशन।

### 5. 🤖 ज्योति दीदी कुकिंग असिस्टेंट (Interactive AI Chat Assistant)
- 24/7 तुरंत कुकिंग सवालों के हिंदी जवाब।
- त्वरित समाधान चिप्स (Quick chips) और सीधा व्हाट्सएप एस्केलेशन।

### 6. 📞 व्हाट्सएप व कॉलिंग कनेक्टिविटी (Direct WhatsApp & Calling)
- 1-क्लिक सीधा व्हाट्सएप चैट (`wa.me`)।
- डायरेक्ट मोबाइल कॉलिंग बटन (`tel:`).

### 7. 🛡️ सुरक्षित एडमिन कंट्रोल पैनल (Admin CMS Dashboard)
- यूज़रनेम: `admin`
- पासवर्ड: `jyoti123`
- नई रेसिपी, मसाला फॉर्मूला और टिप्स जोड़ने/हटाने की सुविधा।
- फोन नंबर, व्हाट्सएप नंबर, थीम और यूपीआई पेमेंट क्यूआर कोड बदलने की पूर्ण स्वतंत्रता।

### 8. 💳 फुटर कस्टमाइज़ेबल UPI पेमेंट क्यूआर कोड (UPI Scan & Pay)
- वेबसाइट के फुटर में डाइनैमिक UPI QR कोड कार्ड।
- डायरेक्ट पेमेंट मॉडल, प्रीसेट राशि (₹51, ₹101, ₹251, ₹501) और UPI ID कॉपी करने की सुविधा।

## 🚀 कैसे चलाएं (How to Run)

### विकल्प 1: सीधा ब्राउज़र में खोलें (Direct Browser)
`index.html` फाइल पर डबल-क्लिक करके किसी भी ब्राउज़र (Chrome, Edge, Firefox) में खोलें।

### विकल्प 2: लोकल नोड सर्वर से चलाएं (Node.js Server)
```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/jyotimasalabox-svg/jyoti-masala-box.git

# फोल्डर में जाएं
cd jyoti-masala-box

# सर्वर शुरू करें
node server.js
# या
npm start
```
इसके बाद ब्राउज़र में जाएं: **http://localhost:3000**

## 🛠️ प्रयुक्त तकनीक (Tech Stack)
- **Frontend**: HTML5, Modern CSS3, Vanilla JavaScript (ES6+)
- **Styling**: Tailwind CSS (CDN), Custom CSS Glassmorphism
- **Fonts**: Google Fonts (`Outfit`, `Rozha One`, `Yatra One`)
- **Icons**: Lucide Icons
- **Animation**: HTML5 Canvas 3D Particle Physics (Rose Petals Rain)
- **Local Server**: Lightweight Node.js HTTP Server (Zero Dependencies)
